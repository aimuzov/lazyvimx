# Полная конфигурация lazyvimx

Весь lazyvimx через `core.all`: все 50 экстр, 39 оверрайдов и кастомные кеймапы.

## Что включено

- ✅ Базовый LazyVim
- ✅ Все экстры lazyvimx
- ✅ Все оверрайды плагинов
- ✅ Кастомные кеймапы
- ✅ Дополнительные цветовые схемы

## Кому подходит

- Хочется максимум возможностей из коробки
- Подобранный набор фич вызывает доверие
- Разбираться с каждой экстрой отдельно лень

## Что внутри

- **Интерфейс (21 экстра)** — диагностика у курсора, счётчики символов, единый стиль окон,
  файловый менеджер Yazi
- **Навигация (6)** — движения по подсловам, перемещение и перестановка узлов дерева,
  разбивка/склейка блоков
- **Git (4)** — ревью GitLab MR, разрешение конфликтов, просмотр удалённых репозиториев
- **Буферы (4)** — группы, автоочистка, изоляция по табам, безопасные sshfs-маунты
- **Производительность (4)** — остановка неактивных LSP, автообновление Mason, локальные
  конфиги проектов

Полный список — на странице [справочнике экстр](../../docs/EXTRAS.ru.md).

## Установка

1. Скопируйте `init.lua` в `~/.config/nvim/init.lua`
2. Запустите Neovim и дождитесь установки плагинов
3. Перезапустите Neovim

## Настройка

`~/.config/nvim/lua/plugins/lazyvimx.lua`:

```lua
return {
	"aimuzov/lazyvimx",
	opts = {
		colorscheme = "tokyonight",
		bufferline_groups = {
			["Components"] = "components/",
			["Pages"] = "pages/",
		},
	},
}
```

## Не нужно всё?

Замените `core.all` на выборочные импорты:

```lua
{ import = "lazyvimx.extras.core.overrides" },
{ import = "lazyvimx.extras.ui.better-diagnostic" },
{ import = "lazyvimx.extras.motions.langmapper" },
```

Или начните с [минимального примера](../minimal/).
