# Минимальная конфигурация lazyvimx

Только оверрайды плагинов, без экстр.

## Что включено

- ✅ Базовый LazyVim
- ✅ Оверрайды плагинов lazyvimx (39 модулей)
- ❌ Экстры — ни одной

## Кому подходит

- Хочется LazyVim с аккуратной доводкой, но без новых фич
- Экстры удобнее включать по одной и осознанно
- Важен полный контроль над тем, что загружается

## Установка

1. Скопируйте `init.lua` в `~/.config/nvim/init.lua`
2. Запустите Neovim — всё установится само

## Дальше

Включайте экстры через `:LazyExtras` или в конфиге:

```lua
{ import = "lazyvimx.extras.ui.better-diagnostic" },
{ import = "lazyvimx.extras.motions.langmapper" },
```

Что бывает — в [справочнике экстр](../../docs/EXTRAS.ru.md).
