# Конфигурация для русской раскладки

lazyvimx с langmapper: Vim-движения работают на русской раскладке — переключаться на
английскую не нужно.

## Что включено

- ✅ **langmapper** — трансляция русской раскладки
- ✅ Экстры движений (работают с русской раскладкой)
- ✅ Оверрайды lazyvimx
- ✅ Рекомендуемые UI-экстры

## Как это работает

Экстра `motions.langmapper` настраивает `langmap` и автоматически транслирует все кеймапы:

| Русская | Английская | Действие         |
| ------- | ---------- | ---------------- |
| `ц`     | `w`        | Следующее слово  |
| `и`     | `b`        | Предыдущее слово |
| `ш`     | `i`        | Режим вставки    |
| `р`     | `h`        | Влево            |
| `о`     | `j`        | Вниз             |
| `л`     | `k`        | Вверх            |
| `д`     | `l`        | Вправо           |

Работают и leader-комбинации: `<Space>аа` делает то же, что `<Space>ff`.

Дополнительно настроены:

- хак `getcharstr` — команды, ожидающие ввода (`f`, `t`, регистры), понимают русские клавиши
- фильтр which-key — подсказки без дублей от транслированных кеймапов
- интеграция со Snacks

## Установка

1. Скопируйте `init.lua` в `~/.config/nvim/init.lua`
2. Запустите Neovim
3. Пользуйтесь Vim-движениями на русской раскладке

## Что транслируется

- все движения: `рлод` (hjkl), `ц`/`и`/`у` (w/b/e), `а`/`е` (f/t)
- операторы: `в`/`с`/`н` (d/c/y)
- leader-кеймапы и кеймапы lazyvimx

**Не транслируется** (и не должно):

- insert-режим — русский текст печатается как обычно
- командный режим (`:` команды)
- терминал

## Если не работает

1. Проверьте, что экстра включена: `:LazyExtras` → `motions.langmapper`
2. Перезапустите Neovim после включения
3. Проверьте маппинг клавиши:

   ```vim
   :verbose map ц
   ```

## Альтернатива: автопереключение раскладки

Если привычнее автоматическое переключение самой раскладки — на macOS есть
[Punto Switcher](https://yandex.ru/soft/punto/), на Linux —
[xkb-switch](https://github.com/grwlf/xkb-switch). Но langmapper проще: раскладку вообще не
нужно трогать.
